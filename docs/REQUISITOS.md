# Especificação de Requisitos — Madson Training

## 1. Requisitos Funcionais (RF)

| ID | Descrição | Status |
|---|---|---|
| RF01 | Visualização categorizada de treinos (Academia: Treino A e B; Casa: Rotina 1 e 2). | Implementado |
| RF02 | Sistema de accordions expansíveis para alternância de rotinas e ambientes. | Implementado |
| RF03 | Controle individual de séries com alternância de estado (pendente/concluída). | Implementado |

| RF05 | Persistência automática do progresso das séries no `localStorage`. | Implementado |

| RF07 | Controles de cronômetro: Iniciar, Pausar e Reiniciar. | Implementado |
| RF08 | Notificações visuais (Toast), sonoras (Web Audio) e vibração ao término do descanso. | Implementado |
| RF09 | Modal de consulta de referências de exercícios (vídeos, imagens e GIFs sob demanda). | Implementado |
| RF10 | Botão de reinicialização global do progresso com confirmação explícita do usuário. | Implementado |
| RF11 | Alternância entre tema escuro (dark gold) e tema claro. | Implementado |
